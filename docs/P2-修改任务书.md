## 1. 总体目标与验收原则

1. **零行为变更**：除字体族选择与文档表述外，用户可见行为必须与 P1 验收基线完全一致（27 项回归全绿）。
2. **可测试性**：核心逻辑（命名、冲突、快照、文件操作）必须能在无 GUI、无第三方依赖的环境下被 `unittest` 覆盖。
3. **可复现**：依赖与打包方式必须落盘为文件（`requirements.txt` + `FileRenamer.spec`），不再依赖口头命令。
4. **单一事实源**：`README.md` 为唯一权威文档，发布副本与其同步，不再漂移。
5. **不新增运行时依赖**：仅声明既有依赖（`ttkbootstrap` 及其传递依赖 `pillow`）。

### 1.1 明确的非目标

- 不新增重命名策略（正则替换、递归目录、撤销/重做等属新需求）。
- 不改动 `file_ops.py` 的两阶段算法与回滚语义。
- 不删除 `code_sum.py`（历史单体版本，已被 `.gitignore` 忽略），仅不纳入构建。
- 不引入 pytest / flake8 / mypy 等新工具链，统一用标准库 `unittest`。

## 5. 风险、兼容性与回滚

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 重构引入行为偏差 | 逻辑搬迁可能改变冲突/快照判定 | 迁移时保持逐行等价，并以 P1 的 27 项验收 + 新增单测双重比对 |
| 循环导入 | `rename_core` 依赖 `helpers`，`main` 依赖两者 | 依赖方向单向：`helpers` ← `rename_core` ← `main`；`ui_theme` 独立于 `helpers` |
| 字体探测异常 | 某些环境 `tkfont.families()` 抛异常 | 用 try/except 兜底 `TkDefaultFont` |
| spec 与 PyInstaller 版本差异 | 本机为 6.21，用户环境可能更旧 | spec 采用 6.x 通用写法，README 注明版本要求 |
| CI 无 GUI | Ubuntu 无 tkinter 显示 | 测试只覆盖无 GUI 模块，CI 不安装 ttkbootstrap |

**回滚方式**：

```powershell
git checkout -- main.py helpers.py dialogs.py README.md
git rm -r --cached rename_core.py ui_theme.py tests requirements.txt FileRenamer.spec .github 2>$null
Remove-Item -Recurse -Force rename_core.py, ui_theme.py, tests, requirements.txt, FileRenamer.spec, .github
```
